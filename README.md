# Portfolio

This folder is prepared for GitHub Pages hosting.

## Publish steps

1. Create a new GitHub repository named `portfolio`.
2. Upload everything from this folder into that repository.
3. In GitHub, open `Settings` > `Pages`.
4. Set `Source` to `Deploy from a branch`.
5. Choose branch `main` and folder `/ (root)`.
6. Save and wait for GitHub Pages to publish.

Your project site URL will be:

`https://YOUR_GITHUB_USERNAME.github.io/portfolio/`
